# MySQL/PostgreSQL 数据库管理功能实施计划

## 总览

新增「数据库管理」能力,分三部分:

1. **实例注册**(设置 → 数据库):登记 MySQL/PostgreSQL 实例(主机/端口/用户/密码),密码经 vault 密封,支持连接测试、编辑、删除;实例默认**只读模式**,需显式解锁才可写(服务端强校验 + 审计)。
2. **phpMyAdmin 式管理页**(顶部导航「数据库」,独立页 `/databases`):库/表浏览、表结构、数据分页浏览+行内增删改、SQL 控制台(只读模式白名单+只读事务双保险)、建/删库、删/清空表、**导出**(SQL/CSV)、**导入**(.sql)、**数据库用户管理**(建用户/改密/授权/删除)。
3. **应用市场联动**:部署 mysql/postgres 模板成功后自动注册实例(复用 RustFS→对象存储的联动先例,同 engine+host+port 幂等轮换密码)。

权限:全部挂 requireAdmin 组(仅管理员);审计 action `dbadmin.*`,SQL 内容不进审计(防 CREATE USER 等语句中的凭据字面量泄漏)。

## 一、后端

### 1. 依赖与迁移

- `go get github.com/jackc/pgx/v5`(用其 stdlib 适配 database/sql,纯 Go)。MySQL 驱动已在 go.mod。
- 新迁移 `internal/store/migrations/sqlite/0082_db_instances.sql` + `mysql/0082_db_instances.sql`:

```sql
CREATE TABLE db_instances (
  id TEXT PRIMARY KEY, name TEXT NOT NULL,
  engine TEXT NOT NULL,            -- mysql | postgres
  host TEXT NOT NULL, port INTEGER NOT NULL,
  username TEXT NOT NULL,
  password_sealed BLOB NOT NULL,   -- vault SealSecret 密文,绝无明文
  tls TEXT NOT NULL DEFAULT '',    -- '' | 'skip-verify'
  readonly INTEGER NOT NULL DEFAULT 1,
  source TEXT NOT NULL DEFAULT 'manual',  -- manual | appstore
  server_id TEXT NOT NULL DEFAULT '', stack_name TEXT NOT NULL DEFAULT '',
  created_at TEXT NOT NULL, updated_at TEXT NOT NULL
);
CREATE UNIQUE INDEX idx_db_instances_endpoint ON db_instances(engine, host, port);
```

### 2. 领域包 `internal/dbadmin/`(新)

文件与职责:
- `dbadmin.go` — `Instance` 模型、`Service` 接口、错误哨兵(ErrNotFound/ErrInvalidEngine/ErrReadonly/ErrVaultUnconfigured/ErrNoPrimaryKey 等)、实例 CRUD store(双方言直写 SQL,风格同 objectstore)。
- `conn.go` — 按实例开连接:解密密码 → 构 DSN(**mysql.Config.FormatDSN() 免转义**;pgx 走 `postgres://` URL,`url.UserPassword` 转义)→ 每请求新建 `*sql.DB` 用完即关(connect 5s / query 60s 超时,免缓存失效问题)。导入走 multiStatements(MySQL)/ simple_protocol(PG)专用 DSN。
- `meta.go` — 服务端信息(VERSION)、库列表(MySQL: information_schema.schemata + tables 聚合行数/大小;PG: pg_database + pg_database_size)、表列表(MySQL: information_schema.tables;PG: pg_class/pg_namespace 非系统 schema,含 schema 限定)、列结构(MySQL: information_schema.columns;PG: pg_attribute + format_type)、索引、主键列。
- `browse.go` — 分页浏览(`LIMIT/OFFSET`、排序列白名单=表实际列、自由 WHERE 条件)、COUNT、按主键取单行/INSERT/UPDATE/DELETE(标识符反引号/双引号转义,无主键表拒绝行编辑)。
- `query.go` — SQL 控制台:单语句;SELECT/SHOW/EXPLAIN/DESC/DESCRIBE/VALUES/WITH 白名单分类;**readonly=1 时一律包只读事务(`START TRANSACTION READ ONLY`)+ 回滚**;结果上限 1000 行/单格 64KB;Exec 返回 RowsAffected。
- `ddl.go` — 建/删库(标识符严格校验 `[A-Za-z0-9_-]+`)、删表、清空表;全部要求非只读。
- `users.go` — 用户管理:MySQL(mysql.user 列表 / CREATE USER / ALTER USER 改密 / SHOW GRANTS / GRANT·REVOKE 模板:全部|只读|增删改查)/ DROP USER;PG(pg_roles 列表 / CREATE ROLE LOGIN / ALTER ROLE 改密 / has_database_privilege 权限矩阵 / GRANT CONNECT+SCHEMA USAGE+默认权限 / REVOKE / DROP ROLE)。用户名/主机走严格字符校验后拼接。
- `export.go` — 流式导出:表或整库;格式 SQL(MySQL 附 `SHOW CREATE TABLE` 的 DDL,PG 数据-only INSERT 并注明;NULL/二进制/转义正确处理)或 CSV;5 分钟/大小上限,超限截断加注释标记。
- `importsql.go` — .sql 多语句导入(≤32MB,10 分钟超时,要求非只读)。
- `*_test.go` — sqlite 上的实例 CRUD/幂等注册/readonly 切换、标识符转义与语句分类单测(不依赖真实引擎)。

密码密封复用 `vault.Vault.SealSecret/OpenSecret`(同 mesh 先例,不占 credentials 表,无需改 vault.Delete 守卫)。

### 3. HTTP 层 `internal/httpapi/dbadmin.go`(新)+ `router.go`

新 Option `WithDBAdmin(dbadmin.Service)`,挂载进 **requireAdmin 子组**(同 mountMeshAdmin 位置)。路由(`/api/db-instances` 前缀,全部过既有 auth+CSRF 中间件):

| 方法 | 路径 | 说明 |
|---|---|---|
| GET/POST | `/api/db-instances` | 列表(无密码)/ 注册 |
| PUT/DELETE | `/{id}` | 编辑(指针字段,密码可选轮换)/ 删除 |
| POST | `/{id}/test`、`/test` | 测已存实例 / 测未存凭据(回版本号) |
| PUT | `/{id}/readonly` | 解锁/上锁(审计) |
| GET | `/{id}/info`、`/{id}/databases` | 服务端信息 / 库列表 |
| POST/DELETE | `/{id}/databases`、`/{id}/databases/{db}` | 建库 / 删库 |
| GET | `/{id}/databases/{db}/tables` | 表列表 |
| GET | `/{id}/databases/{db}/tables/{t}/structure` | 列+索引+主键 |
| GET/POST/PUT/DELETE | `/{id}/databases/{db}/tables/{t}/rows` | 分页浏览(排序/过滤参数)/ 插入 / 更新 / 删除(主键定位) |
| POST | `/{id}/databases/{db}/tables/{t}/drop`、`/truncate` | 删表 / 清空(写操作) |
| POST | `/{id}/query` | SQL 控制台 {database, sql} |
| GET | `/{id}/users`、POST `/{id}/users` | 用户列表 / 创建 |
| POST | `/{id}/users/password`、`/grant`、`/revoke`、DELETE `/{id}/users` | 改密 / 授权 / 回收 / 删除 |
| GET | `/{id}/export?database&table&format` | 流式导出(Content-Disposition) |
| POST | `/{id}/import` | {database, sql} 导入 |

错误映射 `writeError` + 错误码(`db_readonly` 403、`db_instance_not_found` 404、`db_connect_failed` 502 等);`X-Pipewright-Locale` 本地化:主要错误消息注册进后端 i18n catalog(新 `messages_dbadmin.go`,8 语言)。

### 4. 应用市场自动注册(apps.go + main.go)

- `makeDeployAppHandler` 增加 `dbAdmin dbadmin.Service` 参数(router.go 注入点同步);`appAutoRegisterTemplate` 单常量改为集合 {rustfs, mysql, postgres}。
- 新增 `registerDatabaseInstance`(镜像 registerRustFSObjectStore):mysql → root/`root_password`/`port`;postgres → postgres/`password`/`port`;name=`MySQL · <服务器名>[ · 实例]`;source=appstore、server_id、stack_name 落库;同 engine+host+port → 原地轮换密码(幂等);**不做部署内连接测试**(容器首启初始化慢,由管理页 info/测试按钮兜底),独立 20s 超时、尽力而为不影响部署结果;响应新增 `dbRegistered/dbNote`,审计 `dbadmin.instance.register`。
- `cmd/pipewright/main.go`:`dbAdminSvc := dbadmin.New(st.DB, credVault)` + `WithDBAdmin(dbAdminSvc)`。

## 三、实施顺序与验证

1. 迁移 + dbadmin 领域包(实例 CRUD/连接层)+ 单测 → `go test ./internal/dbadmin/...`
2. HTTP 层实例端点 + 设置页 + i18n → `go build ./...`
3. meta/browse/query/ddl + 管理页核心(浏览/结构/控制台/建删库)
4. 行编辑、用户管理、导出、导入
5. 应用市场联动 + AppStore.vue 提示
6. 验证:`go vet ./... && go test ./...`;`cd web && npm run test && npm run build`;手动冒烟(启动后端,注册本地/应用市场 MySQL 实例走一遍只读浏览→解锁→行编辑→导入导出)。

**安全纪律**(贯穿):密码仅密文 BLOB、响应/日志/审计绝无明文;readonly 服务端强校验;标识符一律校验+引号转义;SQL 不进审计;导入/查询限时限量;全部管理员权限 + CSRF + 审计。
