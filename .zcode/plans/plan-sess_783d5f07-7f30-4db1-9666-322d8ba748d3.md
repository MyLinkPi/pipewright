# 集成 acme.sh 自动签发 + 重建证书管理页 + 移除 Caddy 体系

## 已确认的方向（用户拍板）
- **一并移除**旧 Caddy 反代体系（internal/proxy、/api/proxy/*、容器页「域名/反代」面板等）
- 签发验证**仅 DNS-01**（复用已集成的 Cloudflare/DNSPod/阿里云 DNS 提供商凭据，天然支持泛域名）
- 续期由**平台后台调度**（Sweeper 定时检查，到期前 30 天自动续期，每次续期 UI 可见）
- acme.sh 使用自维护 fork（本地 `C:\Users\xufan\Trae\acme.sh`，即 github.com/szxufan/acme.sh，带官方风格 Dockerfile：alpine + supercronic，dnsapi 含 dns_cf/dns_dp/dns_ali）
- 默认 CA：Let's Encrypt（创建时可选 ZeroSSL / BuyPass）；密钥类型默认 EC-256（可选 EC-384 / RSA-2048）

## 架构设计

**新包 `internal/certmgmt`**：证书领域层。acme.sh 跑在**服务注册网关主机**上的专用容器（`pipewright-acme`，`sleep infinity` 常驻工具箱，不带 cron——平台是唯一续期驱动），挂两个卷：
- 网关 nginx 具名卷（servicereg settings.volume_name）→ `/etc/pipewright`，签好的证书经 `acme.sh --install-cert` 直接写到 nginx 约定路径 `/etc/pipewright/certs/<base_domain>/{fullchain,privkey}.pem`
- 独立卷 `pipewright_acme` → `/acme.sh`（ACME 账户密钥/域配置持久化）

**凭据安全**：DNS 提供商凭据绝不进命令行/日志。平台生成一次性 shell 脚本（secret 用标准单引号转义 `'\''`，域名/CA/密钥类型均过白名单正则）→ `tg.Upload` 到宿主 /tmp → `docker cp` 进容器 → `docker exec sh /tmp/issue-<id>.sh` → 执行完即删（宿主+容器）。与 servicereg「固定常量 sh -c」同一例外纪律。

**数据流（签发/续期同一条路径）**：异步 goroutine 执行 → ensure 容器 → `acme.sh --issue/--renew --dns dns_cf -d … --server letsencrypt` → `--install-cert` 到每个被 SAN 覆盖的 servicereg 基域目录（+规范化主域目录做稳定回读点，`*.` 前缀替换为 `_wildcard.`）→ `docker exec cat` 读回 fullchain/key → `tls.X509KeyPair` 校验+解析叶子（subject/issuer/notBefore/notAfter/SANs）→ SealSecret 密文入库（status=issued）→ 经注入的 CertSink 调 `servicereg.Service.UploadCert` 同步匹配的基域（其内部 applyBestEffort 自动 nginx -t + reload）。失败 → status=failed + 人话 status_detail。

**DB（migration `0055_certmgmt.sql`，sqlite+mysql 双方言，仿 0049 风格）**：`certificates` 表：id、primary_domain（唯一索引）、domains（逗号分隔 SAN）、source（acme|manual）、ca、validation（dns|manual）、dns_provider_id、key_type、auto_renew、status（pending|issued|failed）、status_detail、cert_pem_sealed/key_pem_sealed BLOB、subject、issuer、not_before、not_after、last_issued_at、last_attempt_at、created_at、updated_at。`proxy_routes` 表保留不删（非破坏性迁移）。启动时一次性幂等回填：`service_reg_domains` 既有密封证书 → 生成 source=manual 的 certificates 行（老数据在证书页可见）。

**Sweeper**（仿 `internal/retention/sweeper.go` 模式）：默认 1h（env `PIPEWRIGHT_CERT_SWEEP_INTERVAL`，0 关闭），对 source=acme ∧ auto_renew ∧ status=issued ∧ not_after<30天 ∧ 上次尝试>24h 的证书执行续期；进行中用 status=pending + in-flight 锁防重入。

## 实施步骤

### 1. acme.sh 镜像（vendored fork）
- 拷贝本地 fork 的 `acme.sh`、`dnsapi/`、`deploy/`、`notify/`、`Dockerfile` 到 `deploy/acmesh/`（fork 是私有仓库，CI 无法 clone，入库钉版本最稳）
- 新增 `.github/workflows/acme-image.yml`（仿 caddy-image.yml：tag v* + workflow_dispatch，buildx 多架构 amd64/arm64 → `ghcr.io/huangchengsir/pipewright-acmesh`）
- 运行时镜像引用：常量默认值 + env `PIPEWRIGHT_ACMESH_IMAGE` 覆盖（imageRefRe 同款正则校验防注入）

### 2. internal/certmgmt（4 个文件 + 测试）
- `certmgmt.go`：Certificate 模型、Service 接口（List/Create/Import/Renew/Delete/SetAutoRenew/EngineStatus/DeployEngine）、领域错误（人话）、校验（FQDN/通配符复用 proxy 的正则风格；每个 SAN 必须落在所选 DNS 提供商托管的某个根区下——复用 main.go 既有 `dnsResolverAdapter` 的 ProviderZones；通配符必须绑提供商）
- `acmesh.go`：ensureAcmesh（幂等 run 容器、卷、重启策略）、签发/续期/install-cert/回读脚本构造（golden 可测）、GatewayInfo 接口（serverID/volume/network，由 main.go 适配 servicereg settings 注入，避免包环）
- `store.go`：CRUD + 密封 BLOB（仿 servicereg store）+ 回填
- `sweeper.go`：定时续期
- `*_test.go`：脚本构造 golden、校验、store 回环（内存 sqlite）、sweeper 到期判定

### 3. HTTP API（`internal/httpapi/certmgmt.go` + router 注册 + 审计）
- `GET /api/certmgmt/certs`；`POST /api/certmgmt/certs`（ACME 创建，201 返回 pending DTO，异步签发）；`POST /api/certmgmt/certs/import`（手动导入：fullchain+key，`tls.X509KeyPair` 校验，domains 从叶子 SAN 提取）；`POST /api/certmgmt/certs/{id}/renew`（--force）；`POST /api/certmgmt/certs/{id}/auto-renew`；`DELETE /api/certmgmt/certs/{id}`（acme 证书先 `--remove` 停续期不 revoke；若某基域密文与本证书一致则清空并 apply）
- `GET /api/certmgmt/engine`（acme.sh 容器状态：configured/installed/running/image/网关主机名）；`POST /api/certmgmt/engine/deploy`
- DTO 绝不含 PEM/密文；错误映射仿 writeServiceRegError
- main.go 装配：certSvc 构造 + dnsResolverAdapter 复用 + GatewayInfo/CertSink 适配 + Sweeper 启动

### 4. 移除 Caddy（后端）

## 明确的取舍（供审阅）
1. **HTTP-01 不做**（未绑 DNS 提供商的用户走手动导入）
2. **预览环境流量路由本次脱钩**（Caddy 路由没了，子域名+A 记录仍分配；入口反代待基于网关的后续设计）
3. **servicereg 脚本上传证书端点（Bearer token + 公开 POST /api/servicereg/cert）移除**——被平台托管签发取代，统一入口到证书管理页
4. 既有手动上传的基域证书**只读回填**进证书页（密文不可解析 SAN，展示以原 subject/expiry 列为准）
5. 删除 acme 证书不向 CA revoke（LE 无惩罚，避免误操作不可逆）
