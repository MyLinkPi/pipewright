# 应用商店「一键服务注册」实现方案

## 目标

应用商店部署成功后,在结果弹窗中追加「注册到网关」卡片:选基域、填服务名/端口(自动预填)→ 一键完成 `子域名反代注册 + 实例挂载 + 网关收敛`,完成后展示 FQDN。

## 方案要点(零后端改动)

后端能力全部现成,直接复用既有端点(审计 `servicereg.service.create(ensured)` / `servicereg.instance.add` 照常触发):

1. `POST /api/servicereg/services/ensure` — 幂等注册服务(按基域+服务名定位,存在则刷新)
2. `GET/POST /api/servicereg/services/{id}/instances` — 挂载实例,`AddInstance` 内部触发 `applyBestEffort` 自动收敛网关 nginx
3. 实例形态:`container=''`(非容器实例)+ `serverId=部署目标机` + `port=hostPort=宿主端口`(模板 `{{port}}` 参数即 compose 发布的宿主端口;渲染为 `server <服务器IP>:<宿主端口>`)
4. `upstreamKind='address'`、`upstream=''`(http 协议允许为空,实例行携带上游,与 `ServiceRegBinding.vue` 先例一致)

**范围限定**:仅 HTTP 协议(子域名反代)。TCP 需监听端口且领域层限制实例仅 http 服务(`validateInstanceInput` 校验 `ErrNotHTTPService`),TCP 场景引导用户走「服务注册」页完整表单。

## 改动文件

### 1. `web/src/views/AppStore.vue`(主要改动)

**script 部分**:
- 新增 import:`listDomains, ensureService, listInstances, addInstance, removeInstance, getGateway, type Domain`(来自 `../api/servicereg`)+ `useRouter`
- 新增状态:
  ```ts
  const regDomains = ref<Domain[]>([])
  const regGatewayReady = ref<boolean | null>(null)   // null=未知
  const regForm = ref({ domainId: '', name: '', port: '' })
  const regBusy = ref(false)
  const regDoneFqdn = ref('')                          // 非空=已注册成功态
  ```
- `submitDeploy` 成功后异步调用 `prepareReg()`(不阻塞结果展示):并行 `listDomains()` + `getGateway()`;预填
  - `name` = 模板名清洗为 `^[a-z0-9][a-z0-9-]{0,62}$`(小写、非法字符换 `-`)
  - `port` = 从 `deployResult.params` 启发式取:键 `port` 优先,其次 `*_port`,值须为 1-65535 整数
  - `domainId`:仅一个基域时自动选中
- `regPreview` computed:`${name}.${baseDomain}` FQDN 预览
- `submitRegister()`:
  1. 校验基域/服务名/端口齐备,缺失 toast `appStore.deploy.regNeedFields`
  2. `ensureService({domainId, name, protocol:'http', upstreamKind:'address', upstream:'', upstreamPort:Number(port)})`
  3. `listInstances(id)` 去重:存在同 `serverId && container===''` 的行——hostPort 相同则跳过(已注册);不同则 `removeInstance` 后重加(端口已变,刷新)
  4. `addInstance(id, deployResult.serverId, '', port, port)`
  5. 成功:`regDoneFqdn = preview`,toast;失败:`toast.error(errMsg(...))`
- `openDeploy` 重置 `regDoneFqdn` 等注册状态

**template 部分**(结果块 `apps__result` 内、生成口令区块之后):
- `v-if="deployResult.ok && !regDoneFqdn"`:注册卡片
  - 无基域时:`regNoDomains` 提示 + 「前往服务注册」链接(`router.push({name:'service-registry'})`,路由已确认存在于 `web/src/router/index.ts:164`)
  - 有基域:基域 `AppSelect`(复用 `serverOptions` 同款用法)+ 服务名/端口原生 `input.field__in`(沿用本页表单风格)+ FQDN 预览 + `regGatewayReady===false` 时显示「网关未部署,注册会先保存,部署网关后生效」提示 + 提交按钮(loading=regBusy)
- `v-else-if="regDoneFqdn"`:成功态——展示 FQDN + `domain.hasCert` 时附 HTTPS 提示 + 前往服务注册链接
- scoped styles 仿照既有 `apps__params` 区块样式新增 `.apps__reg*`
