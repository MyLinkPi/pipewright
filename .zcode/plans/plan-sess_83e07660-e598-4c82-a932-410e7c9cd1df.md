# 流水线产物管理界面(查看 / 下载 / 删除)

新增管理员「产物管理」页:跨运行列出全部构建产物(文件类 + 镜像类),支持查看详情、下载、删除。基于既有设施(`run_artifacts` 表、`artifactstore` 制品库、`registryhub` 内置镜像仓库)补齐缺口:**跨运行列表端点、删除端点(含 blob 引用计数回收与内置 registry tag 清理)、镜像 tar 导出下载端点**。无 schema 变更、无迁移。

按用户确认的决策:镜像下载 = 服务端 `docker pull + docker save` 流式导出 tar;镜像删除 = 删记录 + 内置 registry tag 一并删除;只做独立管理页,不改 RunDetail 的 ArtifactList。

---

## A. 领域层 `internal/run`

**artifacts.go / service.go(Service 接口同步加方法):**

1. 新错误 `ErrArtifactNotFound`;非终态运行(queued/running/waiting_approval)删除产物 → 新错误 `ErrRunNotFinished`(护栏:进行中运行的产物行是 resume/跨阶段恢复的基线)。
2. `ArtifactFilter{ProjectID, Type, RunID string; Page, PageSize int}`;`ArtifactListEntry`(内嵌 `Artifact` + `ProjectID/ProjectName/RunStatus`);`ArtifactListResult{Items, Page, Total}`。
3. `ListAllArtifacts(ctx, f)`:`run_artifacts a JOIN pipeline_runs pr LEFT JOIN projects p`,过滤 project_id/type/run_id,type 非空时用冻结枚举校验(复用 `isValidArtifactType`);分页/钳制仿 `service.go:501` 的 List(COUNT + `LIMIT ? OFFSET ?`,方言中立);`ORDER BY a.created_at DESC, a.id DESC`。
4. `DeleteArtifact(ctx, runID, artifactID) (*Artifact, orphanKeys []string, error)`:
   - 读运行状态(非终态 → `ErrRunNotFinished`)→ 读产物行(缺失 → `ErrArtifactNotFound`);
   - 计算该产物引用的 blob 句柄:reference 为 64 位 hex + metadata_json 中的 64 位 hex 串(与 `retention/gc.go` 的 hexTokens 同口径,在 run 包内实现小助手);
   - DELETE 行;对每个候选句柄查剩余引用 `SELECT COUNT(1) FROM run_artifacts WHERE reference = ? OR metadata_json LIKE ?`(模式 `%key%` 在 Go 侧拼好作参数,SQLite/MySQL 通用;LIKE 宁可多算引用 = 宁可少删,方向安全);
   - 返回已无引用的句柄(orphanKeys),blob 物理删除交由 HTTP 层。

**测试**:扩展 `artifacts_test.go` — 列表(过滤/分页/排序/关联字段)、删除(行删除、stored 句柄回收、共享句柄不回收、format=files 清单句柄回收、不存在 404、运行中拒绝)。

## B. 镜像导出原语 `internal/build/image_transfer.go`

给 `ImageTransfer` 加两个方法(沿用现有 array 化命令、不经 shell 的约定):
- `EnsureLocal(ctx, ref)`:`image inspect` 不在则 `pull`(内置 registry 无鉴权;外置私有仓库可能失败 → 返回包装的 `ErrImageTransfer`,诚实报错);
- `ExportStream(ctx, ref, w io.Writer)`:`save ref`(不带 -o)把 tar 流式写 stdout → 直接接 HTTP ResponseWriter。

测试:ImageTransfer 无单测注入缝,按现状归入 `e2e_docker_test.go` 风格(或仅构造参数级校验),不强造假命令框架。

## D. HTTP API `internal/httpapi`

**registry_hub.go**:`registryHubService` 窄接口补 `ResolveBuiltin(ctx) (string, bool)` 与 `DeleteTag(ctx, repo, tag) error`(`*Hub` 已实现,main.go 零改动)。

**run_artifacts.go 新增三个 handler(仿本文件既有模式):**
1. `makeArtifactsListHandler(rs)` — `GET /api/artifacts`:query `page/pageSize/projectId/type`(解析与 400 校验仿 `runs.go` 的 makeListRunsHandler);响应 `{items: [artifactDTO 字段 + runId/projectId/projectName/runStatus], page, total}`(新 DTO `artifactRowDTO`,不改冻结的 `artifactDTO`)。
2. `makeArtifactDeleteHandler(rs, store, regHub, aud)` — `DELETE /api/runs/{id}/artifacts/{artifactId}`:
   - run 404 / artifact 404 / 非终态 409;
   - **镜像类且 reference 以内置 registry 地址前缀开头**(`regHub.ResolveBuiltin` 得 `addr`,匹配 `addr+"/"`,拆 repo:tag)→ 先 `regHub.DeleteTag`,失败 → 502 `registry_delete_failed` 且**不动记录**(语义明确可重试);外置 registry 引用跳过此步;
   - `svc.DeleteArtifact` → orphanKeys → 经 `retention.NewBlobStore(store.Root())` best-effort `Remove`(复用 GC 的存储面;store 为 nil 且非镜像类 → 503,与下载端点同语义);
   - 审计 `runs.artifact.delete`(actor/runId/artifactId/name/type/reference);响应 `{"deleted": true}`。
3. `makeArtifactImageArchiveHandler(rs, exporter)` — `GET /api/runs/{id}/artifacts/{artifactId}/image-archive`:type != image → 400 `artifact_not_image`;exporter 为 nil → 503;`EnsureLocal`(失败 → 502 `image_export_failed`,提示需本地容器 CLI / pull 失败)→ `application/octet-stream` + `Content-Disposition`(`<安全化 name>.tar`)→ `ExportStream` 流式输出。

**router.go**:options 加 `artifactExporter`(httpapi 内定义窄接口 `EnsureLocal/ExportStream`,便于测试注入);三条新路由全部挂进 **requireAdmin 管理组**(仿 mountDiskAdmin 区域,用 `o.runs`/`o.artifactStore`/`o.registryHub`)。memberGate 默认拒绝已天然覆盖(member 对新端点 403),白名单零改动,成员既有的按运行查看/下载不受影响。

**测试**:扩展 `run_artifacts_test.go`(或新建 artifacts_admin_test.go)— 列表鉴权/过滤/分页;删除(403/404/409、blob 文件真被删、镜像 + 内置前缀 → fake regHub 收到 DeleteTag、registry 失败 → 502 且行还在);镜像导出(类型错 400、fake exporter 流内容)。

## 已知取舍(实现时遵守)

- 删除产物会影响 CreateResume 的产物继承与跨阶段恢复基线 → 用「非终态运行拒绝删除」护栏兜底,终态运行的删除属管理语义可接受;
- 手动删 blob 与进行中构建的 Put-写行存在极窄竞态(内容寻址去重场景),采用「剩余引用 LIKE 检查、宁可少删」的安全方向,孤儿兜底由每小时 GC 收口;
- 外置私有 registry 的镜像 pull 导出可能因无凭据失败,端点诚实报 502;删除只清记录不动外置 registry。
