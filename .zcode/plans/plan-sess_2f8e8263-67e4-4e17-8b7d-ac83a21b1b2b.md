# 应用商店部署「实例名」维度 + 重名提醒

## 目标

部署对话框支持可选「实例名」：填写后栈目录与 compose 项目名变为 `<模板名>-<实例名>`（如 `gitea-2`），同一台机器可跑同模板多副本（数据卷/网络按 compose 项目前缀自动隔离，无额外改动）；与目标机**现有栈重名**（含实例为空时与默认名重合）时表单实时显示提醒（非阻断）。留空 = 现状，已部署的栈完全兼容。

## 后端：internal/httpapi/apps.go

1. deploy 请求体加 `Instance string`（`json:"instance,omitempty"`，先 trim）。
2. 校验（与 Stacks 部署同规则，复用 `reDockerTgt`，server_ops.go:33）：非空实例名须匹配 `^[\w][\w.-]*$` 且组合名长度 ≤128；非法 → 400 `invalid_app_deploy`（人话文案说明合法字符集）。
3. `stackName := tpl.Name`，实例非空时 `tpl.Name + "-" + instance`；贯穿三处：
   - `deployComposeToServer`（栈目录 `/opt/pipewright/stacks/<stackName>` + `-p <stackName>`）
   - 响应 `name` 字段（改为生效栈名，供前端服务注册预填）
   - 审计 detail 增记 `instance`（非空时）
4. RustFS 联动：`registerRustFSObjectStore` 加 instance 参数，多副本时对象存储配置名带实例后缀（如 `RustFS · 机器A · 2`）以区分。

重名检测**不加后端端点**：前端复用现有 `GET /api/servers/{id}/stacks`（server_stacks.go:136）。

## 前端

### web/src/api/apps.ts
`deployApp` 加可选 `instance?: string` 参数（全仓仅 AppStore.vue 与其测试调用）。

### web/src/views/AppStore.vue
- 部署表单目标机下方加「实例名（可选）」输入框；`openDeploy` 重置。
- 重名提醒：选定目标机后调 `getServerStacks(serverId)`（web/src/api/containers.ts:203）缓存栈名列表（切机刷新）；computed 算生效栈名（模板名或模板名-实例名），与列表比对（大小写不敏感——compose v2 会把项目名转小写）命中时表单内显示非阻断提醒：「该机器已存在同名栈 X，本次将更新它而非新建；数据卷按项目隔离不受影响」。实例为空但默认栈已存在时同样提示（把「重新部署=覆盖」显性化）。机器不可达/拉取失败 → 静默跳过（提醒仅建议性）。
- 实例名格式即时校验（同 reDockerTgt），非法时禁用提交并提示。
- 一键服务注册的子域名预填改用 `deployResult.name`（生效栈名），多副本注册不重名。

### i18n：8 语言 appStore.ts 的 deploy 子树新增 4 键
`instance` / `instanceHint` / `instanceInvalid` / `stackTaken`（zh-CN 文案：实例名 / 留空即默认实例，填写后可同机部署多副本 / 实例名非法：字母数字与 . _ -，不以 - 开头 / 该机器已存在同名栈 {name}，本次部署将更新它而非新建，数据卷按项目隔离不受影响），其余语言按各文件风格翻译（keyParity 测试强制 8 语言一致）。

## 测试

- 后端（扩展 apps_register_test.go，沿用 chi + httptest + fake 模式）：`deployTargetFake.Exec` 增加命令记录；断言 instance=2 时执行命令含 `-p gitea-2` 与目录 `stacks/gitea-2`、响应 `name=gitea-2`、RustFS 配置名带实例后缀；非法实例名 → 400。
- 前端（扩展 AppStore.test.ts）：实例名输入渲染；mock `getServerStacks` 返回同名栈 → 提醒出现，改名/清空 → 消失；机器列表正常但 stacks 请求失败 → 无提醒不报错；提交体携带 instance。

## 不改

appstore 领域层（实例不入库）、Stacks 页与其端点、router.go、模板定义。

## 已知边界

- 栈被 `down`（容器删光）后不再出现在 `docker ps` 聚合列表，提醒会漏报——提醒仅建议性，部署本身幂等，不构成风险。
- 实例名与 Stacks 页手建的栈同名也会提醒并按同名更新（同一命名空间，行为一致）。
