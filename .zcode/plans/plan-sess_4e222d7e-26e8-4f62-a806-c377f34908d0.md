# 服务器文件查看功能（fileadmin）实现方案

仿照 diskadmin（磁盘管理）的既有架构：域服务包 + admin 路由组挂载 + Vue 管理页。可浏览登记服务器的任意目录、下载文件、在线查看/编辑 ≤64KiB 的纯文本文件。目标机为 Linux（GNU find/stat，与 lsblk 先例一致）。

## 后端

### 1. 新域服务包 `internal/fileadmin/`

**`fileadmin.go`** — Service 接口与 DTO：
```go
type Service interface {
    List(ctx, serverID, path) (*DirListing, error)          // 目录列表
    Read(ctx, serverID, path) (*TextFile, error)            // 小文本读取（元数据+内容）
    Write(ctx, serverID, path, content string) error        // 覆盖保存（先备份）
    Download(ctx, serverID, path) (io.ReadCloser, int64, error) // 流式下载 + 大小
}
type DirEntry struct { Name, Path, Type string /*dir|file|symlink|other*/; Size int64; Mode, Owner, Group string; Mtime int64 }
type DirListing struct { Path string; Entries []DirEntry }   // 目录在前、名称升序
type TextFile struct { Path string; Size int64; Binary, TooLarge, Editable bool; Content string }
```
- 哨兵错误：`ErrServerNotFound / ErrInvalidInput / ErrNotFound / ErrNotDir / ErrNotFile / ErrExec`
- 常量 `maxTextBytes = 64 << 10`；`New(servers target.Service, opts ...Option)`，`WithRunner` 供测试注入
- `validatePath`：必须 `/` 开头绝对路径、长度 ≤4096、无 `..` 段、无控制字符（NUL/换行/制表符）；空格等合法字符靠 argv 转义保证安全

**`exec.go`** — 仿 `diskadmin/exec.go` 的 Runner 抽象：
- 接口：`Run / RunWithStdin / Stream(ctx, serverID, cmd) (io.ReadCloser, error)`
- `sshRunner` 提权策略与 diskadmin 不同点：**提权可用则用（root 直跑；非 root 探测 `sudo -n true` 缓存 10 分钟后前缀 `sudo -n`），探测失败不报错、回退登录用户身份执行**——浏览类操作不应因无 sudo 整体不可用；写受限文件时自然得到权限错误
- 非零退出码 → `ErrExec` 包装 + stderr 尾部（tailOutput 同款）

**`browse.go`** — 远端命令与解析（全部 argv 化，`sh -c` 场景路径作位置参数 `$0`，AC-SEC-02）：
- 判型+大小：`sh -c 'LC_ALL=C stat -Lc "%F|%s" -- "$0"' <path>`（`-L` 跟随符号链接，`LC_ALL=C` 消除本地化；不存在 → ErrNotFound）
- List：先 stat 确认目录（ErrNotDir），再 `find -H <path> -mindepth 1 -maxdepth 1 -printf '%y\t%s\t%T@\t%m\t%u\t%g\t%f\n'`，按行 tab 解析（字段 >7 时并入名称，宽容含 tab 文件名；含换行的名称跳过并记日志）
- Read：stat 须常规文件（ErrNotFile）；size > 64KiB → `TooLarge:true, Editable:false`（不报错，前端引导下载）；否则 `sh -c 'head -c 65536 -- "$0"' <path>`，含 NUL 或 `!utf8.Valid` → `Binary:true` 内容为空；否则返回原文 + `Editable:true`
- Write：content 长度 ≤64KiB 校验；stat 须存在且常规文件（防误建新文件，404/ErrNotFile）；**先备份 `cp -a -- "$0" "$1"`**，备份名 = `<path>.pipewright-bak.<UTC时间戳>`（备份失败中止保存），再 `RunWithStdin` 经 `sh -c 'cat > "$0"' <path>` 写入（覆盖保留原 inode 权限/属主）
- Download：stat 须常规文件取 size → `Stream` 跑 `cat -- <path>` 流式返回

**`fileadmin_test.go`** — fake Runner 注入：列表解析（含 tab 容错/排序）、tooLarge/binary 检测、validatePath 表驱动、Write 的备份+写入命令序列断言、退出码映射。

### 2. HTTP 层 `internal/httpapi/fileadmin.go`

```go
mountFileAdmin(ar, svc fileadmin.Service, rec audit.Recorder):
ar.Route("/fileadmin/servers/{id}", func(r) {
    r.Get("/files",  …)              // ?path=/var/log   → DirListing
    r.Get("/file",   …)              // ?path=…          → TextFile
    r.Get("/file/download", …)       // ?path=…          → octet-stream 流
    r.Put("/file",  …)               // body {path, content} → {ok:true}（CSRF+审计）
})
```
- `writeFileAdminError` 错误映射：ErrServerNotFound→404、ErrInvalidInput→400 `invalid_file_input`、ErrNotFound→404 `file_not_found`、ErrNotDir/ErrNotFile→422、ErrExec→502 `file_exec_failed`、默认 500
- 下载 handler：复用 `sanitizeFilename`（run_artifacts.go）；`application/octet-stream` + `X-Content-Type-Options: nosniff` + `Content-Disposition: attachment` + Content-Length + `io.Copy`
- Write handler：`http.MaxBytesReader` 72KB + 审计 `fileadmin.file.write`（Detail: path/bytes/备份名，复用 recordAudit/clientIP/auditActor）

### 3. 路由与装配
- `internal/httpapi/router.go`：options 加 `fileAdmin` 字段 + `WithFileAdmin` Option；admin 子组 diskadmin 旁 `if o.fileAdmin != nil { mountFileAdmin(ar, o.fileAdmin, aud) }`
- `cmd/pipewright/main.go`：`fileAdminSvc := fileadmin.New(targetSvc)` + `httpapi.WithFileAdmin(fileAdminSvc)`

### 4. `internal/httpapi/fileadmin_test.go` — 仿 diskadmin_test.go：fake Service；未登录 401、成员 403、PUT 缺 CSRF 403、各端点 happy path、错误码映射、下载响应头断言。

## 安全要点
- 命令一律 `[]string` argv + target 层单引号转义，`sh -c` 时路径作 `$0` 位置参数，绝不拼 shell
- 路径白名单校验（绝对路径/无 ../无控制字符/限长）为纵深防御
- admin 路由组（requireAdmin）+ 写方法 CSRF + 写操作审计；错误体绝无凭据明文
- 编辑仅限已存在的常规文件且 ≤64KiB，保存前强制 `cp -a` 同目录备份
